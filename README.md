# 🎮 Video Game Sales Prediction

### Machine Learning | Python | Data Science

## 📌 Project Overview

Video Game Sales Prediction is a Machine Learning project that focuses on analyzing historical video game sales data and predicting global video game sales based on various features.

The project explores relationships between game platforms, genres, publishers, release years, and regional sales to understand the factors influencing video game popularity and commercial success.

## 🎯 Objectives

- Analyze historical video game sales data.
- Perform Exploratory Data Analysis (EDA).
- Identify important factors affecting global sales.
- Apply data preprocessing and feature engineering techniques.
- Build Machine Learning models for sales prediction.
- Evaluate model performance using appropriate evaluation metrics.

## 📊 Dataset Information

The project uses a video game sales dataset containing information about:

| Feature | Description |
|---|---|
| Name | Name of the video game |
| Platform | Gaming platform |
| Year | Release year |
| Genre | Game genre |
| Publisher | Game publisher |
| NA_Sales | Sales in North America |
| EU_Sales | Sales in Europe |
| JP_Sales | Sales in Japan |
| Other_Sales | Sales in other regions |
| Global_Sales | Total global sales |

*Note: The exact dataset columns may vary depending on the dataset version.*

## ⚙️ Project Workflow

1. **Data Collection** – Loading the video game sales dataset.
2. **Data Cleaning** – Handling missing values and duplicate records.
3. **Exploratory Data Analysis (EDA)** – Understanding sales trends through visualizations.
4. **Data Preprocessing** – Preparing categorical and numerical features.
5. **Feature Engineering** – Selecting relevant features for prediction.
6. **Model Training** – Training Machine Learning models.
7. **Model Evaluation** – Measuring predictive performance.
8. **Sales Prediction** – Predicting video game sales using the trained model.

## 📈 Key Analysis Areas

- Platform-wise sales analysis.
- Genre-wise sales distribution.
- Publisher-wise sales performance.
- Regional sales comparison.
- Global video game sales trends.
- Relationship between game features and sales.

## 🚀 How to Run the Project

**Option 1: Google Colab**

1. Clone or download this repository.
2. Open the `.ipynb` notebook in Google Colab.
3. Upload the required dataset.
4. Install the required libraries if necessary.
5. Run all cells sequentially.

**Option 2: Jupyter Notebook**

1. Clone the repository:

   ```bash
   git clone https://github.com/Susruta18/Video_Game_Sales_Prediction.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Video_Game_Sales_Prediction
   ```

3. Install dependencies:

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn
   ```

4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open the project notebook and execute the cells.
